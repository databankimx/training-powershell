# 13. Working with This Collection

Everything you've learned so far applies directly to the tutorials and tools in this collection. This chapter puts it to work on them. You'll read a setup script the way you'd read any other script, understand the messages it prints, and know which folder each command has to run from.

Nothing in this chapter is new as a command. The difference is that the examples are real ones from the collection, so when a setup stops, you'll know what it's telling you, and what to do about it.

## What you'll do

1. **Reading a setup script.** Recognize the parts of one, from the header to the stop message.
2. **Reading what a setup says.** Understand the summary it prints, the stop message, and the `-SkipInstall` switch.
3. **Running from the right folder.** Work out where a command has to run, and why `npm start` fails in the wrong place.
4. **Summary.** Put the chapter together, and try the quizzes.

## About the examples

The scripts in the collection are long, so the examples here are short extracts that follow the same patterns. Each exercise is a small script of your own, written to match the style of the real ones. You won't need to run the real setup scripts to finish this chapter.
