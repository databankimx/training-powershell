# 8. Parameters and Functions

A script that always does exactly the same thing is of limited use. The useful ones take input: a folder to look in, a name to greet, a number to repeat. Parameters are how a script receives that input, and functions are how a script organizes its own work into named pieces that can be used again.

Both ideas come up in almost every script you'll read from here on, so it's worth taking them slowly. Nothing in this chapter is difficult on its own. The difficulty is in keeping track of which value goes where, and the examples are designed to make that visible.

## What you'll do

1. **Parameters.** Give a script input with a `param` block, set defaults, and pass values by name.
2. **Functions.** Name a piece of work, give it input, and get a result back.
3. **Switches and checks.** Use on-or-off parameters, and limit what a parameter will accept.
4. **Summary.** Put the chapter together, and try the quizzes.

## A note on how the exercises run

The reader runs each exercise without passing any arguments. That means every parameter in an exercise falls back to its default value, which is why the exercises set defaults. Outside the reader, you can pass whatever values you like, and the examples in each step show both.

## Before you start

You don't need any files for these exercises, and each one starts from an empty script. Open PowerShell 7 before you begin, and check the version if you're not sure.
