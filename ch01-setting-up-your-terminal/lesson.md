# 1. Setting Up Your Terminal

This chapter gets your terminal ready for the rest of the tutorial. It takes about an hour, and most of that is waiting for installers. You'll install PowerShell 7, make Windows Terminal open it by default, and create a practice folder. None of it is hard, but every later exercise assumes all three are in place.

Windows has two programs called PowerShell, and it's easy to end up in the wrong one. This chapter shows you how to tell which one you're in, and how to make sure you're always in the right one.

## What you'll do

1. **Install PowerShell 7.** Check which version is open, and install the newer one with winget.
2. **Make PowerShell 7 the default.** Set Windows Terminal to open it every time, and confirm the edition.
3. **Create your practice folder.** Make the folder the exercises use, with a script.
4. **Summary.** Put the three checks together, and try the quizzes.

Each step has an exercise. The first three check your setup as you go, so if an exercise fails, the setup usually needs another look before you move on.
